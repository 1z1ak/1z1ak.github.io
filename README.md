## 🚀 Engineering Projects

### 1. Digital Alarm Clock — FPGA System
**Technologies:** VHDL, Quartus Prime, ModelSim, FPGA, Digital Logic

Designed and implemented a digital alarm clock using an FPGA development board.

- Developed modular VHDL components, including a clock divider, time counter, finite state machine (FSM), and button debouncer.
- Implemented seven-segment display drivers for real-time clock visualization.
- Designed alarm logic and user interaction through physical input buttons.
- Integrated multiple hardware modules into a top-level controller.
- Implemented Display Time, Set Time, and Set Alarm operating modes.
- Incorporated soft and hard reset functionality.

### 2. AM Radio Receiver — Analog Electronics Laboratory
**Technologies:** Analog Circuits, TL072 Op-Amp, 1N914 Diodes, Circuit Prototyping

Designed and assembled an AM radio receiver as part of an electronics laboratory project.

- Built and tested a radio frequency tuning circuit using a homemade inductor.
- Implemented an AM signal detection circuit using diode-based rectification.
- Designed a headphone amplifier using a TL072 operational amplifier.
- Worked with discrete electronic components, including resistors, capacitors, and diodes.
- Evaluated circuit performance through experimental testing and troubleshooting.

### 3. Blackjack Game — Object-Oriented Programming
**Technologies:** C++, Object-Oriented Programming, Data Structures

Developed a terminal-based Blackjack game using object-oriented programming principles.

- Implemented the main game controller to manage game flow and player interactions.
- Developed card and hand management using custom classes and a vector-based data structure.
- Implemented a linked-list-based card deck.
- Designed card comparison logic using rank and suit, including duplicate prevention.
- Implemented input validation and terminal interface formatting.
- Incorporated flexible Ace valuation to support Blackjack rules.

### 4. Digital Signal Processing — MATLAB
**Technologies:** MATLAB, Signal Processing, Numerical Analysis

Applied MATLAB to analyze and manipulate discrete-time and continuous-time signals.

- Implemented signal scaling, downsampling, and upsampling through manual indexing.
- Developed audio signal processing operations using imported WAV files.
- Implemented echo effects using delayed and attenuated signal components.
- Explored discrete-time convolution and system response.
- Analyzed signal transformations, periodicity, and linear time-invariant systems.
