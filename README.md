## 🚀 Engineering Projects

### 01. Digital Alarm Clock — FPGA Development

**Technologies:** VHDL · FPGA · Quartus Prime · ModelSim · Digital Logic

Designed and implemented a functional digital alarm clock using an FPGA development board, integrating multiple digital hardware modules into a complete system.

- Developed modular VHDL components, including a clock divider, time counter, finite state machine (FSM), and button debouncer.
- Implemented seven-segment display drivers to display real-time clock information.
- Designed alarm functionality and user interaction through physical input buttons.
- Integrated individual modules using a top-level controller.
- Implemented multiple operating modes, including Display Time, Set Time, and Set Alarm.
- Incorporated soft and hard reset functionality for clock operation and alarm control.

---

### 02. AM Radio Receiver — Analog Electronics

**Technologies:** Analog Circuits · TL072 Op-Amp · 1N914 Diodes · Circuit Prototyping

Designed, assembled, and tested an AM radio receiver as part of an electrical circuits laboratory project.

- Constructed an LC tuning circuit using a self-made inductor and capacitors to select AM radio frequencies.
- Developed a diode-based envelope detector to recover the audio signal from the received AM waveform.
- Integrated a TL072 operational amplifier to amplify the recovered audio signal for headphone output.
- Assembled the circuit using discrete electronic components, including resistors, capacitors, and diodes.
- Performed circuit testing and troubleshooting to evaluate signal reception and overall functionality.
